# Christmas Pool website

Local static website for **Christmas Pool: Holiday Shots**.

- Open `index.html` directly or serve this directory with any static HTTP server.
- `privacy.html` and `terms.html` contain the public legal pages.
- `holiday-pool-art.png` is generated promotional artwork and is labeled as such on the page; it is not a gameplay screenshot.
- `app-icon.png`, `favicon-64.png`, and `apple-touch-icon.png` contain the generated Christmas 8-ball identity used by the site.
- The site has no analytics, cookies, forms, external fonts, or runtime dependencies.
- This package is prepared locally and has not been deployed.

Before publication, the developer should review the legal pages for the final release configuration, target countries, age rating, reward rules, and the Google Play Data safety answers.
